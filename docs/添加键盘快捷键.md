# 添加键盘快捷键

> 经验总结，基于已落地实现：系统级「Ctrl+Shift+, 开关设置」、应用内「Ctrl/Cmd+F 聚焦搜索」。

## 一、先选型：两条路线

| 路线 | 实现方式 | 适用场景 |
| --- | --- | --- |
| **系统级** | Rust 侧 `tauri-plugin-global-shortcut` 注册，前端 `listen` 事件 | 应用失焦也需响应（如设置开关 Ctrl+Shift+,） |
| **应用内** | 标准 Web API `document.addEventListener('keydown')` | 仅页面激活/获得焦点时响应（如 Ctrl+F 聚焦搜索） |

**选型原则**（Tauri v2 官方建议）：应用内快捷键一律用标准 Web API 监听 `keydown`，**只有系统级才用插件**。主页功能快捷键没有失焦需求，不要引入 global-shortcut 插件。

## 二、系统级：Ctrl+Shift+, 开关设置（参考实现）

**Rust 侧**（[lib.rs](../src-tauri/src/lib.rs)）：

```rust
// 全局快捷键：Ctrl+Shift+, 切换设置面板（系统级钩子，不受输入法/WebView 焦点影响）
#[cfg(desktop)]
{
    use tauri::Emitter;
    use tauri_plugin_global_shortcut::{Code, Modifiers, Shortcut, ShortcutState};
    let toggle_settings = Shortcut::new(
        Some(Modifiers::CONTROL | Modifiers::SHIFT),
        Code::Comma,
    );
    app.handle().plugin(
        tauri_plugin_global_shortcut::Builder::new()
            .with_shortcuts([toggle_settings])?
            .with_handler(move |app, shortcut, event| {
                if shortcut == &toggle_settings && event.state() == ShortcutState::Pressed {
                    let _ = app.emit("global-shortcut", "toggle-settings");
                }
            })
            .build(),
    )?;
}
```

要点：`Cargo.toml` 加 `tauri-plugin-global-shortcut = "2"`；仅 `ShortcutState::Pressed` 触发；事件名 + payload（动作字符串）约定。

**前端**（[App.vue](../src/App.vue)）：

```ts
let unlisten: (() => void) | undefined;
onMounted(async () => {
  unlisten = await listen("global-shortcut", () => {
    settingsOpen.value = !settingsOpen.value;
  });
});
onUnmounted(() => unlisten?.());
```

**教训**：组合键可能被系统其它程序占用全局热键，插件无法抢占——原 `Ctrl+,` 冲突，故加 Shift 改为 `Ctrl+Shift+,`。

## 三、应用内：Ctrl/Cmd+F 聚焦搜索（参考实现）

背景：Tauri v2 文档明确区分——应用内监听用 DOM 事件，不占用插件；KeepAlive 页面用 Vue 官方激活生命周期控制注册/注销。

```ts
// KeepAlive 路由页面：仅当前激活页面响应，切换页面后不残留监听
const searchInput = ref<HTMLInputElement | null>(null);
function onSearchKeydown(e: KeyboardEvent) {
  if ((e.ctrlKey || e.metaKey) && e.code === "KeyF") {
    e.preventDefault();
    searchInput.value?.focus();
  }
}
onActivated(() => document.addEventListener("keydown", onSearchKeydown));
onDeactivated(() => document.removeEventListener("keydown", onSearchKeydown));
```

（非 KeepAlive 页面用 `onMounted` / `onUnmounted` 配对即可。）

要点：

- 判定用 `e.code`（物理键位 `"KeyF"`），非 `e.key`，避免输入法/布局影响
- 修饰符 `e.ctrlKey || e.metaKey` 兼容 Mac ⌘
- 命中后 `e.preventDefault()` 拦截浏览器原生行为（如 Ctrl+F 查找）

## 四、通用注意事项

1. **输入框守卫**：焦点在 `input` / `textarea` / `select` 时优先让编辑类按键放行（参考 NavAndIndex：检查 `e.target.tagName`），避免拦截输入。
2. **Esc 的语义归属**：导航组件不响应 Esc；Esc 由各弹窗/面板自行决定，避免全局硬编码。
3. **全屏接管**：全屏查看器用 `window.addEventListener("keydown", fn, true)`（capture 阶段）+ `stopPropagation` 拦截下层详情弹窗，`onUnmounted` 内 `removeEventListener(..., true)` 对称清理。
4. **生命周期对称**：注册与注销必须成对；KeepAlive 用 `onActivated`/`onDeactivated`，普通页用 `onMounted`/`onUnmounted`，防止残留监听导致切页后幽灵触发。
5. **动作语义字符串**：插件事件 payload 用可读字符串（如 `"toggle-settings"`），便于扩展多个全局快捷键。

## 五、与 pm（prompt-manager）对照

pm 通过 `ShortcutManager`（renderer 统一注册表 + `contextStack` 上下文）实现全局快捷键。paim 的轻量做法：**按需在页面内注册**，避免抽象一个全局管理器——除非快捷键数量明显增多（届时可参考 pm 的“注册表 + 动作分发”模式）。

pm 主页相关快捷键（参考值）：`Ctrl+F` 聚焦搜索、`Ctrl+P`/`Ctrl+I` 主页切换、`Ctrl+T` 标签面板、`F5` 刷新、`Ctrl+A` 全选、`Ctrl+Shift+Delete` 回收站。
