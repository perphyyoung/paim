# 通用语言（DDD 统一语言）

本文件记录跨前后端共享的业务术语（项目内专属，非通用计算机概念）。所有代码、UI 文案、文档中的使用须与此处定义一致。

**分工**：本文件只定义「叫什么、指什么」（术语与口径，含权威代码位置），不写操作步骤；怎么装、怎么用、怎么排障见 [README.md](README.md)。

## 特殊标签

权威名单：前端 `src/features/tag/specialTags.ts` 的 `SPECIAL_TAG_NAMES` 与后端 `src-tauri/src/domain/list_query.rs` 的 `SP_*` 常量。修改任一处必须同步另一处。

| 中文术语 | 英文术语     | 定义                                                                                     | 避免使用的别名                     |
| -------- | ------------ | ---------------------------------------------------------------------------------------- | ---------------------------------- |
| 收藏     | favorite     | `is_favorite = true` 的条目；两域通用（图像 / 提示词）；主页筛选、详情切换、批量收藏共用 | 收藏夹                             |
| 安全     | safe         | `is_safe = true` 的条目；两域通用；两域各自可切换，跨域联动写库                          | 安全评级、is_safe                  |
| 敏感     | unsafe       | `is_safe = false` 的条目；两域通用；两域各自可切换，跨域联动写库                         | **不安全**（已废弃）、danger、nsfw |
| 未引     | unreferenced | 图像域：未被任何提示词引用；提示词域无此筛选                                             | 未被引用、孤儿图像                 |
| 多引     | multiRef     | 图像域：被 ≥2 个提示词引用；提示词域无此筛选                                             | 多次引用、被多处引用               |
| 多图     | multiImage   | 提示词域：关联 ≥2 张图像；图像域无此筛选                                                 | 多图像、关联多图                   |
| 无图     | noImage      | 提示词域：未关联任何图像；图像域无此筛选                                                 | 无关联图像                         |
| 无标     | noTag        | 未打任何普通标签（不含特殊标签）的条目；两域通用                                         | 无标签、未分类                     |
| 单语     | singleLang   | 提示词域：content 和 translation 只有一个非空；图像域无此筛选                            | 单语言、未翻译                     |

| 中文术语 | 英文术语      | 定义                                                                                                                     | 避免使用的别名     |
| -------- | ------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------ |
| 孤儿文件 | orphan_file   | 磁盘 `images/` 或 `thumbnails/` 目录下存在，但数据库 images 表无对应 `relative_path` 或 `thumbnail_path` 的文件          | 垃圾文件、孤立文件 |

## 目录

各类目录的路径与命名口径。权威定义：`src-tauri/src/infra/db.rs`（数据/临时目录族）、`infra/webview_dir.rs`（WebView 目录）、`infra/logging.rs`（基目录）、`domain/backup_common.rs`（备份临时目录）。

| 中文术语         | 英文术语          | 定义                                                                                                                                                                                                                       | 避免使用的别名                              |
| ---------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| 数据目录         | data dir          | 业务数据根，内含 `paim.db`、`images/`、`thumbnails/`、`font-family-map.toml`。解析优先级：`PAIM_DATA_DIR`（e2e 隔离）→ debug：项目根 `paim-data/` → release：`%APPDATA%\com.paim.perphyyoung`。设置页「数据目录」即此路径，多套数据集靠整目录改名切换 | 数据库目录、资源目录、paim-data（仅指 debug 下的默认目录名） |
| 图像目录         | images dir        | 数据目录下 `images/{YYYYMM}/`，存原图；`images.relative_path` 以此为基准                                                                                                                                                    | 图片目录、原图目录                          |
| 缩略图目录       | thumbnails dir    | 数据目录下 `thumbnails/{YYYYMM}/thumb_*.jpg`；`images.thumbnail_path` 以此为基准                                                                                                                                           | 缩略图缓存                                  |
| 字体家族映射文件 | font-family-map   | 数据目录下 `font-family-map.toml`，`"英文族名" = "中文名"`；首次展开字体家族下拉时自动写入默认模板                                                                                                                          | 字体名映射、font-name-map                   |
| 临时目录         | temp dir          | 运行中临时文件（上传预览图等）的根目录，**必须在数据目录之外**——否则预览图句柄会挡住备份导入的整目录改名（os error 5）。debug：项目根 `temp/`；release：`%LOCALAPPDATA%\com.paim.perphyyoung\temp`；正常启动时整体清空（跳过 `e2e-*`/`wv2-*`/`preview-*`） | 缓存目录、tmp                               |
| 预览目录         | preview dir       | 临时目录下 `preview-<实例标识>`，存上传预览图；实例标识 = `PAIM_DATA_DIR` 末段（如 `e2e-w0`），无则为 `main`                                                                                                                 | 上传目录                                    |
| 单元测试临时目录 | test temp dir     | `<项目根>/temp/test/<name>-<纳秒>/`，随应用下次启动一并清空                                                                                                                                                                | 测试目录                                    |
| WebView 目录     | webview dir       | **专指 `EBWebView`**：`%LOCALAPPDATA%\com.paim.perphyyoung\EBWebView`。存字体授权决定、localStorage（字号缩放、字体家族选择等界面偏好）与 WebView 缓存，**与业务数据无关**；删它只重置界面偏好（字体授权被拒后靠删它重新授权，界面偏好可用「用户偏好」导出/导入找回）  | 数据目录、用户数据目录、UDF                  |
| WebView 用户数据文件夹 | webview UDF | `%LOCALAPPDATA%\com.paim.perphyyoung`（Tauri 为 WebView2 强制指定的 user data folder，`EBWebView` 是其子目录）。**不要删它本身**——同级的 `temp/`、`logs/` 都在其中，要删的是其下的 `EBWebView`                                    | WebView 目录（混指父目录）                   |
| 基目录           | base dir          | `paim-config.toml` 与 `paim.log` 所在目录：debug 为项目根，release 为进程工作目录                                                                                                                                          | 配置目录、应用目录                          |
| 系统临时目录     | system temp dir   | pm 备份导入解压用（`std::env::temp_dir()`），与「临时目录」不是一回事                                                                                                                                                       | 临时目录（混指两者）                        |

数据目录**同级**的目录命名规则（`paim-data` 为 debug 默认名，release 下以实际数据目录名为前缀）：

| 命名                  | 含义                                                                                | 触发                        |
| --------------------- | ----------------------------------------------------------------------------------- | --------------------------- |
| `<数据目录名>.<名字>` | 备用数据集（如 `paim-data.工作`）；改名切换用，启动防呆靠它判断「切换未完成」        | 用户手工改名                |
| `<数据目录名>_<时间戳>` | 导入备份时原数据目录整体让位到此（如 `paim-data_20260918-120000`）；下划线命名不触发启动防呆 | 备份导入 / 数据集替换      |

表中的 `<时间戳>` 统一为**本地时间 `YYYYMMDD-HHMMSS`**（15 字符，第 9 位是连字符），唯一产出点是前端 `src/utils/date.ts::fileTimestamp()` 与后端 `infra/time.rs::file_stamp()`——跨语言无法共享代码，**改格式必须两端同步**。用到它的命名：`paim-backup-<时间戳>.zip`、`paim-preferences-<时间戳>.json`、`orphan_files_<时间戳>/`、让位备份目录。<br>反例：`db.rs` 生成记录 ID 用的是无连字符的 `%Y%m%d%H%M%S`，用途不同，不要与上面混为一谈。

两条禁止混用（UI 文案与文档都适用）：**WebView 目录 ≠ 数据目录**；**临时目录 ≠ 系统临时目录**。
